# Harika Şeyler Dükkânı – Döşemealtı kategori sayfaları (taslak)

Bu klasörde yalnızca fiziksel mağazanın tanıtımına yönelik kategori alt sayfaları bulunur.

- /dosemealti/bijuteri/ — 01 Bijuteri & Aksesuar
- /dosemealti/kirtasiye/ — 02 Kırtasiye
- 03 Oyuncak ve 04 Hediyelik Eşya: henüz hazırlanmadı, ana sayfadaki bölümlere yönlendiriliyor.

Her kategoride index.html, category.css ve category.js vardır. Kullanılan dört WebP dosyası /dosemealti/assets/ altında tutulur; mevcut sticky-discovery görsellerinin aynı Git blob'ları kullanılmıştır.

**Önemli:** Bu klasör GitHub taslağıdır; Turhost'a aktarılmadı. Sayfalarda arama motorları için noindex bulunur. Canlıya alma öncesinde Turhost'taki /dosemealti/ ana sayfası ile eşitlik, bağlantılar, canonical/robots, gerçek ürün fotoğrafları ve kategori bağlantıları kontrol edilmelidir. Ana sayfa burada kopyalanmamıştır; logo/geri dönüş bağlantıları yayın adresine yönlendirir. Ürün stoku veya fiyatı bildirilmez.

Dil ilkesi: Türkiye Türkçesi, doğal ve samimi, abartılı veya birebir çevrilmiş pazarlama kalıpları olmadan.
