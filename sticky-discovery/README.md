# Harika Şeyler Dükkanı — Sticky Discovery

Kundenansicht: https://kemcap.github.io/harikaseylerdukkani/sticky-discovery/

Statische Webseite mit HTML, CSS, JavaScript und lokalen Bilddateien. Kein Build erforderlich. Enthält die aktuelle Gestaltung, Kontaktangaben, Öffnungszeiten und Überschriftenstruktur. Die Vorschau ist für Suchmaschinen auf noindex gesetzt. Google-Rezensionen werden über einen Link zum Unternehmensprofil geöffnet.
